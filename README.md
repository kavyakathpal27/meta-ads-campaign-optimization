# Meta Ads Campaign Performance & Budget Optimization

## Project Overview
Analyzed 1,143 Facebook advertising records
using Python, Pandas, SQL, and statistical KPI analysis.

## Business Objective
Evaluate advertising efficiency across campaigns
and audience segments, and simulate potential
budget reallocation opportunities.

## Technologies
- Python
- Pandas and NumPy
- SQLite and SQL
- Matplotlib and Seaborn
- Google Colab

## Dataset
Facebook Ads Click Conversion Tracking dataset
(Kaggle, loveall/clicks-conversion-tracking).

## Key Results
- Total records: 1,143
- Total impressions: 213,434,828
- Total clicks: 38,165
- Total spend: 58,705.23
- Approved conversions: 1,079
- CTR: 0.02%
- CPC: 1.54
- CPA: 54.41

## Features
- Data quality checks
- Advertising KPI calculations
- Campaign and audience analysis
- SQL-based performance analysis
- Data visualizations
- Interactive budget reallocation simulator
- Automated business insights

## Methodology
Performance metrics use aggregate ratios.
Budget simulations assume historical CPA
remains constant after reallocating spend.

## Limitations
- Historical observational dataset
- No time-series campaign data
- No verified revenue or ROAS
- Budget simulation is not a causal estimate
- Spend currency must be verified from source
